JS Autos — EV dealership website

A multi-page website for an electric-scooter dealership with four showrooms in Punjab — a filterable model catalog, online test-ride booking, a petrol-vs-electric savings calculator and an admin panel.

Overview

JS Autos is a complete website for an electric-scooter dealership with showrooms in Mohali, Kharar, Badali and Sirhind. It moves a walk-in, phone-call business online: customers can browse every model, compare specs, work out how much they’d save, and book a test ride at the showroom nearest to them.

It’s rendered with PHP on the server and made interactive with vanilla JavaScript — no front-end framework — using Bootstrap 5 for the grid and a hand-written design system on top. Each model page is rendered from its ID, and the booking and enquiry forms post to dedicated PHP endpoints protected by CSRF tokens and a honeypot field to keep spam bots out.

What I built

Filterable catalog

10 models across City and Premium series, with category tabs, live search and sorting.

Test-ride booking

A booking modal pre-selects the model, then asks for showroom, date and a preferred time slot.

Savings calculator

Sliders for daily distance, petrol price, mileage and electricity rate show monthly, yearly and 5-year savings.

Detailed model pages

An image gallery, key specs, a full specification table and similar-model suggestions for every scooter.

Spam-resistant forms

Booking and enquiry endpoints check a CSRF token and a hidden honeypot field before accepting a submission.

Admin panel

A separate admin area behind a CSRF-protected email and password sign-in.

What this project shows

  • A server-rendered, multi-page PHP site with clean, ID-based model pages
  • Interactive UI in plain JavaScript — filters, modals, animated counters and a live calculator
  • Form security basics: CSRF tokens, honeypot spam protection and server-side endpoints
  • Conversion details for a local business: WhatsApp click-to-chat, tap-to-call and embedded Google Maps
