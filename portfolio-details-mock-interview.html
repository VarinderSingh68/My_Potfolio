Overview

AI Mock Interviewer is an Android application built with Kotlin and Jetpack Compose that delivers realistic, interactive mock interview sessions tailored to modern tech hiring. Candidates select their target discipline (Software Developer, Android Developer, Backend, Frontend, Data Scientist, DevOps Engineer, QA Engineer, or Product Manager), choose their round (Full loop, HR, Technical, Design), and define their experience level from Fresher to Senior.

Interviews can be taken entirely hands-free using on-device voice transcription with real-time waveform visualization, or answered via text input. For maximum privacy, voice answers are transcribed locally on the device and audio is never retained on any server.

Each response is scored across three critical dimensions: communication clarity, spoken confidence, and technical depth using Google Gemini AI. To ensure the app is bulletproof in production, it implements a dual-engine architecture: if Gemini or the network is ever unreachable or rate-limited, a deterministic built-in scoring engine seamlessly takes over so interviews never fail or stall mid-question.

Behind the scenes, a lightweight Cloudflare Worker paired with a Cloudflare D1 (serverless SQLite) database plans question sequences, dynamically deploys follow-up probes when an answer is thin, and optionally customizes questions to match a pasted job description with gap detection. A full browser demo of the exact same flow runs at the same URL so anyone can try it without installing anything, and the 14 MB Android APK is directly downloadable right from that page.

What I built

Native Jetpack Compose UI

A fluid dark interface designed with Material 3 principles, interactive role grid cards, custom robot interviewer avatars, round toggles, and smooth state transitions.

Voice & Text Answering

Practice speaking out loud with tap-to-talk microphone controls and live audio waveform animation. Transcription runs on-device, preserving user privacy with zero audio retained.

Dual-Engine Scoring Architecture

Evaluates answers on communication, confidence, and technical depth with Gemini AI — falling back automatically to an internal deterministic engine if offline so sessions never crash.

Adaptive Follow-up Probing

When a candidate provides a brief or thin answer, the engine dynamically interjects a targeted follow-up question to test practical knowledge and depth under pressure.

Tailored to Job Descriptions

Paste any job vacancy text to trigger specialized question planning aligned with the role requirements, followed by an automated gap analysis highlighting missed concepts.

Cloudflare Worker & D1 Database

Fast global edge routing, tokenized guest and authenticated sessions, and persistent interview state backed by serverless SQLite on Cloudflare D1.

Detailed Feedback Reports

Comprehensive end-of-interview report with per-dimension breakdowns, “What stood out” insights, constructive improvement suggestions, and actionable pro-tips.

Instant Web Demo & Direct APK

Zero-barrier evaluation: a responsive web demo runs the complete 3-question interview flow directly in any browser, while the 14 MB native Android APK can be side-loaded anytime.

What this project shows

  • Native Android engineering: Built in modern Kotlin with Jetpack Compose declarative UI, coroutines for asynchronous IO, and clean separation between UI state and network requests.
  • Fail-safe AI architecture: Graceful degradation strategy using Gemini API for deep contextual assessment with a deterministic scoring engine fallback so the user experience is never interrupted.
  • Privacy-conscious audio pipeline: Audio is transcribed locally on the Android device; only text transcripts are transmitted for assessment, ensuring zero sensitive audio is stored.
  • Edge infrastructure & serverless SQL: Powered by Cloudflare Workers and D1 database for sub-100ms response times worldwide, dynamic prompt orchestration, and session history management.
