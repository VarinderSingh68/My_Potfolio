Pet Shop Business Growth Agent

Project Information

  • Category: Full-Stack Web App
  • Type: Personal Project
  • Live Site: pet-shop-business-growth-agent.onrender.com

About This Project

Pet Shop Business Growth Agent is a full-stack e-commerce platform for a pet supply business, demoed here as "Happy Tails." It pairs a shoppable storefront with an admin panel built to actually run the business, not just list products.

Customers shop by pet type (dog, cat, bird, fish), can save a pet profile so the store knows when a bag of food is likely to run out, and can book real appointment slots for grooming, boarding, and vet visits directly from the services page. On the admin side, a dashboard tracks revenue, order status, and new customers, and includes a "Growth Copilot" panel — a feature that analyzes order history to surface concrete opportunities, like which customers are due for a reorder or haven't tried a subscription yet, once there's enough order data for it to work with.
