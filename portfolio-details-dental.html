Overview

Doctor Business Growth Agent is a clinic management platform, demoed as “Dr. Rana Dental Clinic.” It combines a marketing and booking site for patients with an admin dashboard for the practice.

The front end is a React single-page app built with Vite. It talks to a separate REST API deployed on its own, and shows a live backend status indicator so visitors know the booking system is reachable.

What I built

Transparent pricing

Cleanings, fillings, extractions, root canals, cosmetic work and implants, each with a clear price.

Calendar booking

Pick a date and time slot; the clinic confirms within 24 hours.

Live backend status

An indicator that shows whether the API is up — useful on free hosting that sleeps.

Patient portal & chat

A patient portal entry point and a chat widget for quick questions.

Admin dashboard

Manage appointments, services and clinic content.

Email & WhatsApp ready

The API is wired to email and WhatsApp (WATI) messaging services, with its status on a public API page.

What this project shows

  • React + Vite single-page app consuming a separate REST API
  • Date and time-slot booking flows
  • Designing for real deployment conditions, like a sleeping backend
