Overview

ARIA (Advanced Reasoning & Integration Assistant) replaces a pile of separate apps with a single chat. A request is reasoned about and routed to the right tool automatically.

Built-in shortcuts cover the most common jobs — a data visualisation, a document draft, writing and running a script, or drafting and sending a message — and each can also be triggered in plain language. A “Force a specific tool” control overrides the routing when you know exactly what you want, and a Dev Mode gives IT users lower-level control.

What I built

Automatic tool routing

ARIA decides which tool fits the request.

Four built-in tools

Data visualisation, document drafting, script writing and execution, and messaging.

Manual override & Dev Mode

Force a specific tool, or switch to lower-level controls.

Answers from your documents

Upload files up to 200 MB (TXT, DOCX, PDF and more) or ingest a URL.

What this project shows

  • Designing an agent that chooses between tools
